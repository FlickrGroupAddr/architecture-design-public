# Design prototypes

This directory contains disposable interaction artifacts used to test FGA
architecture and product contracts before implementation repositories exist.
They are evidence and discussion aids, not production UI, runtime selections, or
architecture authority.

- [First-publish customer storyboard](first-publish-storyboard/README.md) — a
  dependency-free clickable walkthrough from private setup through a first photo's
  asynchronous group-submission outcomes.
